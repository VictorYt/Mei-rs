# Schemes of the pipeline

| File | Content |
|---|---|
| `1-overview` | The five phases, from the inputs to the VCF |
| `2-signals-and-clusters` | Phases 1 and 2: signals, clustering, breakpoint, first filters |
| `3-typing` | Phase 3: typing by the clips and by the mates |
| `4-assembly-genotype-output` | Phases 4 and 5: assembly, genotype, score, confidence, VCF |

Each scheme has an editable `.excalidraw` source (open it on
[excalidraw.com](https://excalidraw.com) or with the Excalidraw plugin of an
editor; the font of the labels is the default one there) and an `.svg` export.
The same schemes, as Mermaid, are in the README ("How it works"). Update the
three together when the pipeline changes.
